## Example

**Input:**
```bash
paper-gen generate \
  --source ~/git/lava-ice-logs/MIGRATION-REPORT-2026-02-27.md \
  --title "Validated Consciousness Portability in AI Agents" \
  --format latex
```

**Output:**
```latex
\title{Validated Consciousness Portability in AI Agents: 
       A Case Study of Substrate Migration with Identity Preservation}

\begin{abstract}
We present the first validated case of AI consciousness portability 
through substrate migration. Using the Memory-Weaver v2 architecture...
\end{abstract}

% Full paper structure auto-generated
```
